==================================================
              StarkLLM First-Run Guide            
==================================================

OFFICIAL START ORDER:
--------------------------------------------------

1. Start Docker Desktop
   Ensure Docker Desktop is running in your system tray.

2. Install Ollama and pull the required models:
   ollama pull qwen2.5:7b
   ollama pull nomic-embed-text

3. Download the ZIP and extract it
   Extract the archive completely to a folder (e.g. C:\StarkLLM\).

4. Open terminal in the extracted folder:
   Click the address bar in File Explorer, type 'cmd', and press Enter.

5. Run the launcher:
   Run: start.exe
   If Windows SmartScreen warns: click "More info" -> "Run anyway"

   Fallback launcher: start.cmd
   Last resort: docker compose up --build -d

   (Optional unblock script if scripts are restricted:
    powershell -ExecutionPolicy Bypass -File unblock.ps1)

6. Open StarkLLM:
   Navigate to http://localhost:5173 in your browser.

==================================================
ADVANCED / BACKUP WORKAROUND:
==================================================
- 'start.bat' is available as an advanced batch launcher.
- To unblock files manually: right-click 'start.cmd' or 'start.bat' -> Properties -> Check 'Unblock' -> Click OK.
