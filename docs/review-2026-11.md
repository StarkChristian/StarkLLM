# Outside review, November 2026, and what follows from it

An outside review of the whole project (desktop app and engine, Android app, phone link security, website, repository)
on 19 November 2026. Nothing critical or high was found. The largest gap is between what StarkLLM does and what its
texts say: the website, the README and a few messages lagged behind the app. This page is the roadmap that follows.

## Step 1: texts that are true (this pull request)

- The update message no longer says "StarkLLM is not signed yet" (in all six languages): releases are signed since 2.1.2.
- README: version 2.3.0, what the app does today, 13 themes, six languages, models downloaded by the app.
- Release notes: 2.3.0 complete, pull requests listed for 2.2.1 and 2.3.0, the research beta notes marked historical.
- SECURITY.md names the phone link as the one way in from the home network.
- Privacy documents: the engine runs without Docker; how to check and block the engine's own `python.exe`.
- CONTRIBUTING.md.

## Step 2: phone link hardening (desktop)

- A phone question stays on the PC: no web search and no cloud models through the phone link (the docs promise this).
- Wrong pairing codes no longer close an open pairing for everyone (with a 128-bit code they protect nothing).
- Size limits for requests through the phone link.
- Failed sign-ins through the phone link count as failures and are rate limited.
- Writing into a chat (`save-partial`) needs the "work" level, not "ask".
- Honest docs: the fingerprint for "manage" is checked on the phone; the PC trusts the phone's token.

## Step 3: Android app

Stop that really stops, a pairing that survives a stranger answering on the PC's address, kept input when a question is
refused, microphone and camera robustness, text shares, privacy with the app lock (screenshots, notifications, widget),
cloud models hidden, contrast and touch targets, Italian and French wording, a Play bundle in CI, more unit tests.

## Step 4: website

Current version and requirements (no Docker), no dead analytics script, the old signing page replaced, legal pages
current (DDG instead of TMG, the hosting providers named, fonts self-hosted), one coherent product description for
search engines. Publishing waits for the owner.

## Step 5: repository

Stale branches and pull requests closed (with the owner's OK), a repository description, temporary workflows removed.

## Later

- The phone link only on networks Windows marks private.
- A key bound to the fingerprint for "manage" actions on the phone.
- More tests for the app window (React) and its accessibility.
